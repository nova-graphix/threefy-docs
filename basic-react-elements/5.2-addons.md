# 5.2 Addons

The addons part of three.js supported by this threefy is as follows. Additions and updates will continue to be made in the future.

> **Note (v2.0 / WebGPU):** post-processing no longer runs on the WebGL-only `EffectComposer`. Threefy 2.0 drives effects through the node-based **`RenderPipeline`**, so the passes below are wired into a TSL pipeline internally — you still declare them as elements exactly as before. Three new passes are available under WebGPU: `<dotScreenPass/>`, `<rgbShiftPass/>`, and `<fxaaPass/>`.

| Category       | Threefy Elements                                                                                                                                                                                                                                               |
| -------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Controls       | <p>&#x3C;arcballControls /><br>&#x3C;dragControls /><br>&#x3C;firstPersonControls /><br>&#x3C;flyControls /><br>&#x3C;mapControls /><br>&#x3C;orbitControls /><br>&#x3C;pointerLockControls /><br>&#x3C;trackballControls /><br>&#x3C;transformControls /></p> |
| Post-processing <br>(RenderPipeline) | <p>&#x3C;renderPass /><br>&#x3C;shaderPass /><br>&#x3C;glitchPass /><br>&#x3C;gTAOPass /><br>&#x3C;outlinePass /><br>&#x3C;unrealBloomPass /><br>&#x3C;bokehPass /><br>&#x3C;dotScreenPass /><br>&#x3C;rgbShiftPass /><br>&#x3C;fxaaPass /><br>&#x3C;outputPass /></p>                                                                 |
| Camera Effects | <p>&#x3C;anaglyphEffect /><br>&#x3C;asciiEffect /> <sub>(WIP)</sub><br>&#x3C;outlineEffect /><br>&#x3C;parallaxBarrierEffect /><br>&#x3C;stereoEffect /></p>                                                                                                                    |
| Geometries     | <p>&#x3C;roundedBoxGeometry /><br>&#x3C;convexGeometry /><br>&#x3C;decalGeometry /><br>&#x3C;parametricGeometry /><br>&#x3C;textGeometry /><br>&#x3C;teapotGeometry /><br>&#x3C;boxLineGeometry /><br>&#x3C;loftGeometry /></p>                                                                                                                |

> **Note (v2.1):** the control tags above take their constructor arguments automatically — `<orbitControls />` on its own attaches to the scene's camera and canvas. Pass `args` only to override that. See §5.3.3 for `<controls type={…} />`, the single interface covering all of them.

> **Note (v2.1):** `<rGBShiftPass />` and `<fXAAPass />` were renamed to **`<rgbShiftPass />`** and **`<fxaaPass />`**. The old spellings still work but print a deprecation warning once and will be removed in a future release.
